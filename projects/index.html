SELECTED CAREER IMPACT

Security capability.
Built for real constraints.

Selected delivery outcomes across Product Security, security-review capacity, practice building and assurance automation.

These summaries describe career experience. They are not public code repositories or client deliverables.

Scaling Product Security

Challenge: Onboarding and security controls needed to scale across thousands of applications.

Approach: Reusable controls, governance, automation and DevSecOps practices.

Impact: Supported 3,000+ applications and helped reduce onboarding from 60+ days to approximately 25 days.

Building security review capacity

Challenge: Review demand was outgrowing delivery capacity.

Approach: An offshore review capability with standardized delivery.

Impact: Scaled monthly reviews from 2 to 200+ and supported onboarding of 2,000+ applications following an acquisition.

Building a cybersecurity practice

Challenge: Create a commercial security capability from the ground up.

Approach: Services, methodologies, presales, offshore delivery and client engagement.

Impact: Built SGD 2.16M in practice revenue and an 18-month pipeline at QAssure.

Making assurance more repeatable

Challenge: Manual reviews and evidence collection consumed security capacity.

Approach: Automate repeatable vendor due-diligence and ITGC evidence workflows while retaining accountable review.

Impact: Vendor due-diligence effort reduced from 8 to 2 hours; ITGC evidence work reduced from 8 to 4 hours.
